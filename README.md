# eQ Commerce

HTML prototype of the eQ Commerce app (Truxco AB). Every page has a Grid view and an Orbit view.

**Live:** https://azam-shahzad.github.io/eq-commerce/

## Download the whole project

- One click: https://github.com/azam-shahzad/eq-commerce/archive/refs/heads/gh-pages.zip
- Or on GitHub: switch the branch to `gh-pages`, then **Code → Download ZIP**.

Unzip and open `index.html` in a browser. No install or server needed.
