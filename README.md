# eQ Commerce

HTML prototype of the eQ Commerce app (Truxco AB). Every page has a Grid view and an Orbit view.

**Live:** https://azam-shahzad.github.io/eq-commerce/

## Download the whole project

- One click: https://github.com/azam-shahzad/eq-commerce/archive/refs/heads/gh-pages.zip
- Or on GitHub: switch the branch to `gh-pages`, then **Code → Download ZIP**.

Unzip and open `index.html` in a browser. No install or server needed.

## Colour palette

Every page uses one palette of 22 colours plus black. The Figma file uses the same colours as the `Core/…` variables. The blue moon in the background is an image and keeps its own colours.

| Group | Colours |
|---|---|
| Brand | Mint `#8FE6C3`, Cyan `#6FD8EC` |
| Status | Success `#5EE6A0`, Warning `#F2C94C`, Error `#FF3B3B`, Orange `#F0834E` |
| Text | White `#FFFFFF`, Primary `#F1F5F7`, Body `#C3CBCF`, Muted `#A9B3B8`, Faint `#66737A` |
| Surface | Deepest `#0F1518`, Base `#141B1F`, Panel `#1C262C`, Card `#242D32`, Raised `#283238`, Chip `#3A454B` |
| Line | Faint `#323E44`, Default `#4A565C`, Glass `#DCEBF2` |
| Chart | Blue `#8FB4FF`, Coral `#F27459` |
| Other | Black `#000000` |
